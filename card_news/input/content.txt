클로드 코드로 인스타그램 카드뉴스 자동 만드는 방법

클로드 코드를 활용하면 인스타그램 카드뉴스를 자동으로 만들 수 있다. 카드 뉴스를 만드는 것뿐만 아니라 거의 모든 업무의 90% 이상을 클로드 코드로 처리하고 있다.

카드뉴스 제작 방식:
- HTML, CSS로 카드뉴스를 먼저 만들고, Playwright로 스크린샷을 찍어 이미지로 변환하는 방식 사용
- 4:5 비율 (1080×1350px) 사이즈 적용
- 한 장의 커버 이미지, N장의 본문 이미지, 한 장의 CTA 이미지 구성

HTML/CSS 방식을 선택한 이유:
1. AI 이미지 생성 도구와 달리 폰트 크기, 컬러, 간격을 1픽셀 단위로 정확하게 제어 가능
2. 템플릿을 한 번 만들면 100장, 1000장도 같은 퀄리티로 생성 가능
3. 클로드 구독만 있으면 추가 비용 없이 무료로 카드뉴스 제작 가능

카드뉴스 제작 순서:
1. 컨텍스트 수집 - 원하는 링크나 자료를 클로드 코드에게 수집 요청
2. 계획 수립 - 바로 구현하지 않고 플랜 모드로 구조와 디자인 먼저 계획
3. 구현 - 계획 검토 후 HTML/CSS 파일 생성
4. 이미지 변환 - Playwright CLI로 PNG 이미지 변환
5. 스킬화 - 반복 사용을 위해 슬래시 명령어 스킬로 저장

핵심 팁:
- Claude.md 파일은 복잡한 작업이나 클로드가 실수를 반복할 때 작성하면 충분
- 처음엔 계획 모드(플랜 모드)로 결과 확인 후 구현 진행 권장
- 마음에 들 때까지 프롬프트나 직접 코드 수정으로 개선
- 한 번 만든 디자인 템플릿을 스킬로 저장하면 다음 카드뉴스는 훨씬 빠르게 제작

결론:
클로드 코드 + HTML/CSS + Playwright 조합으로 누구나 고품질 인스타 카드뉴스를 자동화할 수 있다. 처음 한 번만 제대로 만들어두면 이후에는 주제만 바꿔서 반복 사용 가능하다.
